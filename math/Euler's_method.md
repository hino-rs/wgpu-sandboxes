# オイラー法

微分方程式を近似的に解くための最もシンプルで基本的なアルゴリズム。

## 前進オイラー法

$$y_{n+1} = y_n + h \cdot f(t_n, y_n)$$

現在地の傾きを使って未来の値を計算する手法。
以下の場合、h=0.015625前後が精度のピークとなる。

```rust
const G: f64 = 9.8; // 重力加速度
const K: f64 = 0.5; // 空気抵抗

fn main() {
    let mut h = 1.0;
    let t_end = 10.0;
    
    while h > 0.000001 {
        let mut v = 0.0; // 速度
        let mut t = 0.0;
        
        while t < t_end - (h / 2.0) {
            v = v + h * (G - K*v);
            t += h;
        }

        println!("h={h}: v={v}");

        h /= 2.0;
    }
}
```

## 後退オイラー法

$$y_{n+1} = y_n + h \cdot f(t_{n+1}, y_{n+1})$$

これから進む未来の場所の傾きを使って未来の値を計算する。

1つ未来のvは以下のように求める。

$$v_{n+1} = \frac{v_n + hg}{1 + kh}$$

コードにすると、

```rust
v = (v + h*G) / (1.0 + K*h);
```

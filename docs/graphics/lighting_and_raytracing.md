# ランバート反射の現実度とレイトレーシングとの関係

床の頂点カラーを `[1.0, 1.0, 1.0]`（真っ白）にしても少し暗いグレーに見えるのは、まさに**「ランバート反射の計算（ライティング）」が完璧に効いている証拠**です！

ここでは、その数学的理由と、「ランバート反射がどれくらい現実に即しているか」、そして「レイトレーシングとの関係」について詳しく解説します。

## なぜ真っ白な床がグレーになるのか？（数学的証明）

現在のシェーダーコードは以下のようになっています：

1. 床のベース色 $C = (1.0, 1.0, 1.0)$
2. 環境光（Ambient）の強さ $A = 0.1$ （10%の明るさ）
3. 光の方向ベクトル $L = \text{normalize}(1.0, 1.0, 1.0) \approx (0.577, 0.577, 0.577)$
4. 床の法線ベクトル $N = (0.0, 1.0, 0.0)$ （真上）

これらをランバート反射の式に当てはめると：

$$\text{Diffuse強度} = \max(N \cdot L, 0.0) = \max(0.0 \times 0.577 + 1.0 \times 0.577 + 0.0 \times 0.577, 0.0) = 0.577$$

最終的な明るさは **「環境光 + 拡散反射光」** なので：

$$\text{最終的な色} = (C \times 0.1) + (C \times 0.577) = C \times 0.677 \approx (0.68, 0.68, 0.68)$$

真っ白（`1.0`）を指定しても、光が斜め（約54.7度）から当たっているため、最終的な出力は**元の色の「約68%の明るさ」**になり、人間の目には落ち着いたグレーとして映ります。数学と物理が完璧に機能している証拠です！

## ランバート反射はどれくらい現実に忠実か？

ランバート反射は**「理想的なマット（つや消し）な質感」**をシミュレートしたものです。

### 現実に極めて忠実な物質（相性が良いもの）

光をすべての方向に完全に均等に散乱させる物質は、ランバート反射で驚くほどリアルに表現できます。

- チョークの表面
- つや消しの紙、コピー用紙
- 乾いた土、粘土
- ザラザラした木肌

### 現実と大きく異なる点（表現できないもの）

1. **テカリ（光沢・ハイライト）がない**:
    プラスチックや金属、濡れた床のような「ツルツルした反射（鏡面反射 / Specular）」が全く表現できません。
2. **見る角度による変化がない**:
    現実の物質は、浅い角度（横から）見るほど反射が強くなってテカテカして見えます（これを**フレネル効果**と呼びます）。ランバートは「どの角度から見ても同じ明るさ」と仮定するため、この変化がありません。
3. **他の物体からの照り返しがない**:
    赤い壁の近くにある白い球体が、少し赤っぽく照らされるような「間接光（グローバル・イルミネーション）」が表現できません。

## 3. レイトレーシングとの関係性は何か？

「ラスタライズ（現在のwgpuの描画方法）」と「レイトレーシング」は、よく対比されますが、実は**敵対する関係ではなく、補い合う関係**です。

### 1. レンダリング手法としての違い

| 比較項目 | 🏎️ ラスタライズ (現在のwgpu) | 📸 レイトレーシング (Ray Tracing) |
| :--- | :--- | :--- |
| **仕組み** | 3Dの頂点を数学的に2D画面に「投影」し、ピクセルごとに色を**直接計算**する。 | 目（カメラ）から数百万本の「光の線（レイ）」を放ち、物体に当たって跳ね返る**旅路を物理シミュレート**する。 |
| **速度** | 爆速（1秒間に数百フレーム描画可能）。ゲームの基本。 | 重い（GPUに巨大な計算負荷がかかる）。最近のグラボでようやくリアルタイム化。 |
| **影・反射** | 他の物体が光を遮る「影」や「鏡の映り込み」は自動で計算できない（別のトリックが必要）。 | **物理的に完璧な影、鏡の映り込み、ガラスの屈折**が自動的に、美しく描画される。 |

### 2. 「ランバート反射」と「レイトレーシング」の美しい関係

実は、**レイトレーシングのプログラムの中でも「ランバート反射」は現役で大活躍しています！**

- **レイトレーシング**: 光線がどこに当たり、どこへ跳ね返るかという **「光の旅の経路」** をシミュレートするシステム。
- **ランバート反射**: 光線がザラザラした物質に当たった時、**「どの方向に、どれくらいの強さで光を散乱させるか」** を決める **「物質の材質ルール（数式）」**。

つまり、レイトレーシングで描かれたリアルな映画やゲームでも、木製テーブルや粘土のキャラクターに光線が当たった瞬間の色の計算には、まさに今シェーダーに書いた `dot(normal, light_dir)` のようなランバートの数式（をより高度にしたもの）が使われているのです！

> [!TIP]
> **ゲーム開発における発展の歴史**
>
> - **ランバート（Lambert）**: 18世紀の数学者ヨハン・ハインリヒ・ランベルトが提唱。マットな反射。
> - **フォン（Phong）**: つや消し（Lambert）に、ツルツルした「鏡面ハイライト」を足したもの。
> - **PBR（物理ベースレンダリング）**: 現代の主流。ランバートをベースに、金属度（Metallicity）や粗さ（Roughness）、フレネル効果を物理的に正しく融合させた最高峰の反射モデル。

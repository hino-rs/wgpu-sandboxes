# 減衰振動

バネにつるされたおもりが、水の中で揺れている様子を表す式。

$$m\frac{d^2x}{dt^2} + c\frac{dx}{dt} + kx = 0$$

- $mx$: おもりの重さ
- $cx$: 動きの抵抗
- $kx$: バネが元に戻ろうとする力

この3つの力が合わさって、最終的に合計が0になっているという状態。

## 連立させる

この式には変化の勢いが2段階入っている。

1. 位置($x$): おもりが今どこにいるか
2. 速度(1階微分): おもりが「どれくらいの勢いで動いているか」(位置の変化)
3. 加速(2階微分): そのスピードが「どれくらいの勢いで増し減りしているか」(速度の変化)

複雑で解きにくいので、2つの式に分ける。

- ➀「位置」が変化すると、「速度」になる式
- ➀「速度」が変化すると、バネや水の抵抗を受けて「加速」が決まる式

式中の $\frac{dx}{dt}$は、「位置$x$の時間変化」つまり「速度」のこと。この速度に新しく$v$という名前を付ける。

$$\frac{dx}{dt} = v$$

これを➀の式とする。

元の式の一番左にある$\frac{d^2x}{dt^2}$は、位置$x$を2回微分したもの。言い換えると、「速度$v$をもう一回微分したもの」となる。

> $\frac{d}{dt}$は、変化を測るもの。後ろに文字を置くと「その文字が1秒間にどれくらい変化するか」を計算してくれる。位置$x$を測るためには、$\frac{d}{dt}(x)$、まとめて$\frac{dx}{dt}$と書く。これは位置が1秒間にどれだけ変わるかと言う意味なので、速度に等しくなる。ので、$=v$と言える。さらに速度$v$も$\frac{d}{dt}(v)$（$ \frac{dv}{dt}$）は速度が1秒間にどれだけ変わるかと言う意味になるので、「加速」を表す。

なので、$v$を用いて以下の様に変換できる。

$$\frac{d^2x}{dt^2} = \frac{dv}{dt}$$

結果、減衰振動の方程式は以下の様に変換できる。

$$m\left({\frac{dv}{dt}}\right) + c(v) + kx = 0$$

式➀と形を揃えるために並び替える。

$$m\frac{dv}{dt} = -kx - cv$$

最後に、左側を$\frac{dv}{dt}$だけにするために、両辺を$m$で割る。

$$\frac{dv}{dt} = -\frac{k}{m}x - \frac{c}{m}v$$

これが➁の式となる。
